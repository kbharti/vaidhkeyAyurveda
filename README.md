# Vaidhkey Ayurveda - Website scaffold

This branch (website) contains a simple static HTML/CSS scaffold for Vaidhkey Ayurveda. Files included:
- index.html, about.html, products.html, contact.html
- products/ (combos, oils, powders, tablets)
- assets/css/styles.css, assets/js/main.js, assets/images/*
- sitemap.xml

Notes:
- Primary color palette: white and green.
- The contact form is static; replace the form action with your preferred endpoint (Formspree, Netlify Forms, etc.).
- Images are placeholders. Replace assets/images/placeholder-*.jpg with real images.

Deployment:
You can enable GitHub Pages on this repository and set it to serve from the website branch root to publish the site.
